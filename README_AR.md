# مدير البلاغات الاجتماعية — واجهة محسّنة

مشروع Android Studio بلغة Java. يتضمن اختيار المنصة، وإدخال رابط/اسم مستخدم، وزري بدء وإيقاف للمتابعة المحلية، وعدّادات للعمليات والتأكيدات اليدوية.

## التشغيل
1. فك ضغط ZIP.
2. افتح المجلد في Android Studio.
3. انتظر مزامنة Gradle ثم شغّل التطبيق.

## مهم
زر البدء يسجل محاولة واحدة ويفتح قناة المساعدة الرسمية للمنصة. زر الإيقاف يوقف حالة المتابعة داخل التطبيق. لا توجد بلاغات آلية أو لا نهائية، ولا يؤكد العداد نجاح البلاغ على خوادم المنصات.
